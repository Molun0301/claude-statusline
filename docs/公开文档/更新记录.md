# 更新记录

## 1.1.0 — 2026-11-18

- 新增 `SubAgent:运行:总数` 段，与额度的 ▸ 一样可点击展开；展开后逐行显示子代理名称、描述和各自的 keepwarm 状态与次数，名称列和描述列对齐。
- Claude 原生子代理行补充保活标记、词元数与耗时，耗时超过一分钟只显示到分钟。
- 展开后的额度改为对齐表格：当前虚拟机在首行，单行放不下时每台虚拟机拆成 5h、7d 两行。
- keepwarm 次数改为 `kw:本轮:累计`；配合 keepwarm 0.12.2，累计加上代理替全部对话做的服务端保活，本轮加上主对话的，子代理行各自计入。
- Tabby 点击处理新增 `claude-quota://keepwarm/会话` 入口，用于展开或收起子代理行。
